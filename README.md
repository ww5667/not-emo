# 心晴 · 情绪日记与自我关怀

一个面向年轻人的低门槛情绪记录、自我洞察与自我关怀产品原型。页面以温和、克制的视觉语言呈现情绪打卡、趋势分析、触发因素以及即时练习推荐。

## 在线展示

仓库已配置 GitHub Pages 自动部署。合并到默认分支后，可在仓库的 **Settings → Pages → GitHub Actions** 查看官方展示地址。

## 本地运行

```bash
python3 -m http.server 4173
```

打开 <http://localhost:4173>。

## 功能

- 六种情绪快速选择与文字补充记录
- 本地保存最近 30 条情绪记录
- 周情绪趋势、记录连续性和触发因素概览
- 呼吸、冥想和舒缓音乐即时推荐
- 响应式桌面端与移动端布局
