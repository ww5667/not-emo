# 此刻 · 情绪日记与自我关怀

一个面向年轻人的低门槛情绪记录与自我关怀产品原型。支持即时情绪记录、每周趋势洞察，以及冥想、音乐和运动建议。

## 在线展示

项目已配置 GitHub Pages 官方 Actions 工作流。将仓库推送至 GitHub 后，在 **Settings → Pages → Source** 中选择 **GitHub Actions**，即可通过 `https://<用户名>.github.io/<仓库名>/` 访问。

## 本地预览

```bash
python3 -m http.server 4173
```

访问 <http://localhost:4173>。
